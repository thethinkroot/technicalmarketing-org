Note de l'éditeur

Cet index s'adresse aux personnes qui font ce travail. Les responsables du marketing technique qui opèrent sans référence commune. Les praticiens qui arrivent dans ce domaine et méritent mieux que des descriptions de poste éparses. Les personnes expérimentées dont le jugement durement acquis n'a jamais été rassemblé nulle part de manière visible.

Le travail existe manifestement. L'industrie manque encore d'un langage commun pour le définir.

Le Volume 01 est un point de départ sélectionné — le dossier, les essais, l'ossature de référence, le kit de terrain, et la réflexion actuelle. Les nouveaux volumes paraissent chaque trimestre. Les espaces vides de l'index sont intentionnels : ils marquent les conversations que le domaine doit encore avoir.

Chad Corriveau · Rédacteur en chef fondateur
